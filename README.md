# Minimal ETL Modeler downloads

Public download channel for Minimal ETL Modeler.

The product source repository is private. This repository intentionally contains no customer data, credentials, telemetry, project files, or application source code. It exists only so release artifacts can be downloaded anonymously.

## v0.14.2 — Browser-only customer distribution

- **Browser / Light ZIP** — extract the archive and open `minimal-etl-modeler/app/index.html`.
- No installer, downloaded launcher, Electron shell, desktop executable, backend, CDN, telemetry, or remote runtime assets.
- Imported customer data remains local to the browser and user-chosen files.

The Electron/Large Windows distribution published with v0.14.1 has been withdrawn. Its ZIP contained the native launcher inherent to Electron and is not suitable for customer endpoints that prohibit unknown executable code. Historical native 10M/25M/50M test results are not browser capability claims.
